# Database-code

Bộ notebook bài tập **cấu trúc dữ liệu và giải thuật**, viết bằng Python.

## Nội dung

| Notebook | Chủ đề |
|---|---|
| `LinkList.ipynb` | Danh sách liên kết |
| `Stack.ipynb`, `queues.ipynb` | Ngăn xếp, hàng đợi |
| `trees.ipynb`, `tree_data.ipynb` | Cây, cây nhị phân |
| `avl_tree.ipynb` | Cây AVL (cân bằng) |
| `hash.ipynb` | Bảng băm |
| `sorts.ipynb` | Các thuật toán sắp xếp |
| `search_methods.ipynb` | Tìm kiếm tuyến tính / nhị phân |
| `ml_review.ipynb` | Ôn tập machine learning |

## Chạy

Mở bằng Jupyter:

```bash
jupyter notebook
```
